# Earth texture credits

The four Earth maps in `src/assets/textures/` are unmodified copies of the matched Earth texture set distributed with the three.js Earth example. Downloaded 2026-10-25 from the three.js `dev` branch and byte-verified against commit `fae873455dff9602a916b4d2e8a985921448b62a`.

Surface, normal and specular maps are 2048 × 1024 JPEG. The cloud map is a 1024 × 512 PNG with a genuine alpha channel (indexed PNG with alpha palette); transparent areas reveal the surface below. All four use matching equirectangular coordinates. They are bundled with the site and do not make runtime requests to an outside image service.

Day/cloud color textures use sRGB. Normal and specular data maps must use linear/no-color-space sampling. The specular map is bright over oceans. Preserve alpha when loading the cloud map.
